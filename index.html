五分钟部署

免费 Cloudflare 账号 + Node ≥ 18 + Wrangler v4，5 分钟完成部署。

1. 部署节点

npm install
npx wrangler login        # 浏览器授权
npx wrangler deploy       # 部署
# 验证（把 <name> 替换为 wrangler 输出的 Worker 名）
curl https://easytier-cf-relay.<你的子域>.workers.dev/health
# 期望: {"ok":true}

配置项可先用 wrangler.toml 生成器 生成；不绑定自定义域名时使用默认 *.workers.dev 域名即可。

2. 客户端接入

easytier-core --network-name myteam --network-secret s3cret! \
  --hostname node-a -p wss://<你的域名>/

任意平台（Windows / macOS / Linux / 手机端）填相同的网络名与密钥即可互见； 节点地址填 wss://<你的域名>/（路径任意）。 

easytier-core \
  --network-name myteam \
  --network-secret s3cret! \
  --hostname node-a \
  -p wss://et.example.com/
  • 网络名称：myteam
  • 网络密钥：s3cret!
  • 节点 / Peer：wss://et.example.com/（新建一个节点条目填入即可）
docker run --name easytier -d --network host --cap-add NET_ADMIN \
  easytier/easytier:latest \
  --network-name myteam --network-secret 's3cret!' \
  -p wss://et.example.com/

本地开发：npm run dev（wrangler dev，端口 8787），用官方客户端连接 ws://127.0.0.1:8787/ 验证。 完整步骤、域名绑定与 FAQ 见 部署手册。

架构

Worker 入口负责路由与边缘防护，Durable Object 负责协议会话与转发；纯 P2P 优先，中继仅兜底。

EasyTier 客户端 A
Windows / macOS / Linux / 手机端
EasyTier 客户端 B
任意平台，同一网络名 + 密钥
EasyTier 客户端 C
P2P 打洞成功后 A ↔ B 直连
wss://你的域名/ · 标准 WebSocket + EasyTier 二进制协议（任意路径）
Cloudflare Edge · Worker 入口（src/index.js）
健康检查 · 自定义 /metrics 与管理端（token 双门禁）· Prometheus 文本指标（v1.6）· 边缘层 IP 黑名单拦截（不唤醒 DO）· 按 URL / Header / Query 选择房间
RelayRoom Durable Object（src/room.js）
握手鉴权 → 路由同步（OSPF）→ 包转发 · 全 Hibernation API + alarm 驱动清扫 · 幽灵节点六重防线
同网络的其他客户端
P2P 打洞成功后直连、不再经过本节点；打洞失败才经中继兜底（可 RELAY_DATA=0 完全关闭）

致谢

本项目站在前人肩膀上。

  • EasyTier — 官方去中心化 mesh VPN。本实现的协议行为全部以官方源码（tag v2.6.4）为基准逐项对齐，并以官方客户端实测验证兼容性。
  • IceSoulHanxi/easytier-ws-relay — 最早的 Cloudflare Workers 版 EasyTier WS 中继之一。其「幽灵节点」痛点直接催生了本项目的六重防线设计。
  • Teleseon/cf-workers-et-ws — 其 DO 计费与 protobuf 兼容性经验直接影响了本项目「全 Hibernation + pbjs 静态代码生成」的技术路线。
  • 21paradox/easytier-wsrelay 与 PIKACHUIM/easytier-worker — 踩过的协议细节坑为本项目「逐字段对照官方源码修正」提供了前车之鉴。
